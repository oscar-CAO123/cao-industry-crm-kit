# CRM shell template: health-care

`template.json` is this industry's template: the department pages (one per core function, ancillary pieces as tabs,
after the health-care demo app's page map), the built workflows this industry's evidence backs, the planned ones, and the
apps it connects to. Apply it in the CRM under Admin, Templates; it shows every change first and can be undone.
Format: `shell/docs/TEMPLATES.md`.
