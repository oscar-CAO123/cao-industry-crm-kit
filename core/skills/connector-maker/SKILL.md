# Connector maker

Check the vendor's terms first, then use the first route that works:

1. Official API or CLI.
2. Hosted or local MCP.
3. Custom CLI against stable endpoints or files.
4. Fixed macro.
5. Computer-use script.

Set `status` honestly: `record-only`, `docs-only`, `sandbox-tested` or `live-tested`.
