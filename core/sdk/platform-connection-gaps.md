# Platform connection gaps

The kit's connection tests use a fake network. A client must supply its own credentials and complete the vendor's onboarding and any required certification before live use.

- **Microsoft Advertising:** Two campaign REST operations, GetCampaignsByAccountId and AddCampaigns, are mapped and tested offline; the other 234 operations remain refused pending scope review. Microsoft also publishes REST endpoints: for example, [GetCampaignsByAccountId](https://learn.microsoft.com/en-us/advertising/campaign-management-service/getcampaignsbyaccountid?view=bingads-13) uses `POST /CampaignManagement/v13/Campaigns/QueryByAccountId`. Its [generated REST client](https://github.com/BingAds/BingAds-Python-SDK/tree/main/openapi_client) supplies routes and request models. The remaining operations need operation-specific account-scope review and tests. Native SDK requests remain refused because their bodies do not yet pass the scope guard. A SOAP transport is not a prerequisite.
- **SiteMinder:** The listed operations span multiple products with different authentication and integration requirements. Channels Plus specifies `x-sm-api-id` and `x-sm-api-key`, but the mapped reference pages do not establish the production base URL for these calls. The kit refuses them until each product's real production host and sign-in are confirmed from SiteMinder's documentation and the integration's required onboarding is complete. [Channels Plus reference](https://developer.siteminder.com/channels-plus-api/reference/properties), [integration requirements](https://developer.siteminder.com/get-started/partner-lifecycle/integration-process.md).
- **ServiceM8:** Add-on and messaging calls require a supplied `SERVICEM8_ADDON_ACCESS_TOKEN`; access tokens expire after one hour. OAuth authorization and refresh are not implemented by the kit. [ServiceM8 authentication](https://developer.servicem8.com/docs/authentication).
- **Dropbox:** Content uploads accept base64 file content up to 10 MiB per request. Larger transfers require chunked upload sessions. Native vendor SDK content calls remain refused by the SDK gate; use the kit's mapped operations. [Dropbox HTTP reference](https://www.dropbox.com/developers/paper-api-alpha).
- **Mailchimp Transactional:** Mapped calls take `MANDRILL_API_KEY` from the secret store and place it in the JSON request body. Native vendor SDK calls using this body-key scheme remain refused by the SDK gate. [Mailchimp Transactional authentication](https://mailchimp.com/developer/transactional/docs/fundamentals/).
